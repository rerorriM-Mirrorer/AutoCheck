# AutoCheck development entry point

Before changing this repository or preparing a testing package, read the current root-level `WORKFLOW.md` and `TESTING.md` directly from GitHub; do not rely on older copies. The canonical shared standards are in [`ffxi-NPCmirror/WORKFLOW.md`](https://github.com/rerorriM-Mirrorer/ffxi-NPCmirror/blob/main/WORKFLOW.md). Preserve known-good behavior and historical test records.

Commit and push coherent changes to development branches, keep the default branch trustworthy, distinguish static/mock results from actual FFXI play, and include README/WORKFLOW/TESTING in installable testing ZIPs. Never publish character-specific `data/` or personal settings.
