# AutoCheck

A Windower 4 addon that automatically sends the game's normal `/check` for a stable, currently targeted monster.

**Repository status — November 10, 2026:** The original v0.1.0 behavior was confirmed working in-game, but the original v0.1.0 source package was not included in the uploaded update. Consequently this default branch is currently documentation-only rather than presenting an unverified version as stable.

The full imported **v0.1.1 candidate** (including the `//ac memory on|off` switch, default OFF) is published on [`development/memory-toggle`](https://github.com/rerorriM-Mirrorer/AutoCheck/tree/development/memory-toggle). It passed simulated tests; the new option still needs in-game acceptance. Download that branch to test it, preserving existing Windower `data/` settings.

The development branch includes installation instructions, source, LICENSE, TESTING.md, WORKFLOW.md, and AGENTS.md. Once the accepted source is established, we can promote it here without rewriting history.
